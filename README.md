# Kagu

Single-file web editor for SVG illustrations (open `index.html` in a browser).

Steps: Upload -> Trace (simplify) -> Cleanup -> Colours -> Export.
Split view with the original on the left and the result on the right.
Raster tracing is not included yet; it needs the Line Art engine on a server.

## Files
- `index.html`: the whole app (HTML, CSS, JS in one file)
- `logo.svg`: bird logo
